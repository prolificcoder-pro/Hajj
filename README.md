# الأخوية | خدمة الأخوية لضيوف الرحمن

> وكالة أسفار مغربية متخصصة في تنظيم رحلات الحج والعمرة الراقية والميسرة، بالدرهم المغربي.

---

## لمحة عن المشروع

موقع إلكتروني عصري لوكالة **الأخوية** المتخصصة في خدمات الحج والعمرة للسوق المغربية. يقدم الموقع واجهة عربية أولى (RTL) بتصميم راقٍ ومينيمالي، مع ميزة فريدة: **«صمّم رحلتك»** — منشئ رحلة خطوة بخطوة يتيح للمستخدم تخصيص برنامج عمرته الكامل واحتساب تكلفته التقديرية بالدرهم المغربي (MAD) قبل التواصل مع الوكالة مباشرةً عبر واتساب.

---

## المميزات الرئيسية

- 🕌 **تصميم عربي أولاً** — RTL حقيقي، طباعة راقية (Alexandria + Amiri)، لوحة ألوان مستوحاة من الهوية البصرية للوكالة
- ✈️ **منشئ الرحلة التفاعلي «صمّم رحلتك»** — 6 خطوات لتخصيص المدينة المنطلقة، المدة، الفندق، النقل، والخدمات الإضافية
- 📦 **باقات الحج والعمرة** — عرض باقات موسمية مع إمكانية المقارنة
- 📋 **دليل المعتمر المغربي** — قوائم تحقق وإرشادات عملية
- 💬 **تواصل فوري عبر واتساب** — رسائل مسبقة الصياغة تتضمن تفاصيل الرحلة المصممة
- 📱 **متجاوب تماماً** — محسّن للهاتف المحمول والحاسوب

| التقنية | الدور |

## التثبيت والتشغيل

```bash
# استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/al-okhowa-hajj.git
cd al-okhowa-hajj

# تثبيت التبعيات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build

# معاينة نسخة الإنتاج
npm run preview
```

## تخصيص بيانات الوكالة

جميع بيانات الاتصال والباقات وخيارات الفنادق والمدن مركزةٌ في ملف واحد:

```
src/data/travelData.js
```

ابحث عن كائن `AGENCY_CONTACT` في نهاية الملف وعدّل:
- رقم الهاتف وواتساب
- البريد الإلكتروني
- العنوان والفروع
- رقم رخصة وكالة الأسفار

## النشر (Deployment)

### GitHub Pages

```bash
npm install -D gh-pages
```

أضف في `package.json`:
```json
"homepage": "https://YOUR_USERNAME.github.io/al-okhowa-hajj",
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}
```

ثم في `vite.config.js` أضف:
```js
base: '/al-okhowa-hajj/'
```

ونشر:
```bash
npm run deploy
```

### Vercel / Netlify

ارفع المستودع على GitHub ثم اربطه بـ Vercel أو Netlify مباشرةً — سيتعرفان على Vite تلقائياً.
